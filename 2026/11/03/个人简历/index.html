项目经验

1. 在线考试系统

  • 项目简介：该系统是一个实现数据采集（数据读取、数据匹配、数据保存、数据接收/发送…）、数据整合的系统。
  • 技术实现：core java、socket 编程
  • 职责：独立完成项目编码
  • 心得：这是一个阶段性的项目，是对于之前学习的 core java 基础知识的综合运用。觉得自己对 core java 基础知识和 socket 编程的运用有了新的理解，同时也开始接触到 MVC 设计模式，觉得运用这个模式进行开发，不仅可以让整个软件系统的层次分明，而且在维护的时候更加的方便、快捷。

2. 网上订餐系统

  • 项目简介：通过 web 应用程序，有订单系统和管理系统两个独立的模块构成，有购物车，客户能选择自己喜欢的食物，通过链接网上银行对食物进行购买，管理系统，管理员能对食物进行上架和下架操作，能修改食物的信息等。
  • 开发工具：MyEclipse、Tomcat、SQLServer
  • 技术实现：corejava、socket、jsp+javascript+ajax
  • 心得体会：担任组长，自己了解整个项目的开发流程，分配开发任务，协调开发工作，帮助组员解决开发过程中遇到的问题。这是第一个团队协作完成的项目，对于自身的团队协调能力和沟通能力是一个锻炼。这也是第一个 web 项目，使自己对其认识加深，锻炼了自己的代码能力。通过这个系统，对 MVC 模式有了深入了解，对它给我们带来的好处深有体会，层次分的很清楚，不至于牵一发而动全身，有利于代码的调试。但也有自己的不足，对一个简单的界面，遵循 MVC 反而增加了结构的复杂性。

3. 云南省农村信用社卡客户管理系统

  • 项目简介：系统整体功能划分成 9 个功能模块，分别为：基础要素、客户管理、VIP 卡管理、客户经理管理、客户增值服务管理、客户经理工作平台、统计与分析、VIP 卡年费管理、系统管理与部分接口。整个系统以客户信息为基础，通过对 VIP 客户信息的管理，将客户与客户经理、客户与增值服务、客户与 VIP 卡的信息进行关联管理，形成一个综合的 VIP 客户信息管理系统，设计开发整个客户信息管理系统的目的是帮助客户经理和客户经理主管对我社的 VIP 客户进行管理，客户经理在日常维护 VIP 客户时，能根据客户的信息，有的放矢的进行维护和营销工作，增强客户经理对客户的管理能力，提升客户经理对 VIP 客户的服务能力。
  • 开发工具：eWAP、MyEclipse、Tomcat 等
  • 技术实现：corejava、socket、javascript、html+js、Jquery 等
  • 总结与体会：该项目是我真正参加工作的第一个项目，从项目开始到结束的整个过程我都有参与，在开发过程中，团队的合作是很重要的，沟通也十分的重要，在这里，我学到了很多知识，包括做人的道理。这段时间里我在领导和同事们的关心与帮助下完成了各项工作，在思想觉悟方面、办事能力方面都有了很大的提高。我热衷于本职工作，严以律己，摆正心态，时刻保持“谦虚，谨慎，律己”的工作态度，在领导的关心培养和同事们的支持帮助下，始终勤奋学习，积极进取，努力提高自我，勤奋工作，履行好岗位职责，认真完成各项任务。

4. 民生银行外包项目

  • 项目简介：主要做一些关于 DB2 和流程的优化分析，提高其执行效率，做数据的一些提取工作，数据的优化处理，一些流程的优化，把多个流程节点合并成一个，做了相应的单元测试，并进行优化前后效率的对比和分析。
  • 开发工具：DBVisualizer、MyEclipse、Tomcat 等
  • 技术实现：corejava、socket、javascript、html+js、Jquery 等
  • 总结与体会：该项目是我首次接触 DB2 数据库，从中学到了很多关于 DB2 的一些知识，对数据库有了更多的了解，对一些流程处理也有一些方法，在这期间，我学到了好多的新东西，如，用 sqlldr 来导数据，对流程开发工具也有一些了解。特别是让我的 sql 水平也有了很大的提高。

5. 信贷项目和人保项目

  • 项目简介：在信贷项目里我主要负责档案的管理，包括档案的录入、查询、删除和更新，档案包括电子档案和实物档案，电子档案需要上传附件和一些介质，在查看档案可以下载查看相关的附件资料，在这，我学到了文件的上传和下载，里面有很多的逻辑控制，使自己的逻辑思维也有了很大的提高。人保项目主要负责人保数据的导入，用了 plsql 导入工具进行数据导入，后来自己也写了 java，从后台也可以导入，在 excel 模板里输入相关的数据，调用后端代码进行数据的导入操作。
  • 开发工具：eWAP、MyEclipse、plsql、Tomcat 等
  • 技术实现：corejava、socket、javascript、html+js、Jquery 等
  • 总结与体会：通过这两个项目，我学到了很多的东西，认识到一个团队协作完成这个项目的重要性，一个人的力量是有限的，在有限的时间里要完成一个项目需要团队一起努力，相互协作和相互帮助，如果遇到你自己不能解决的困难，就需要团队人的帮助，一起来解决这个困难，在项目里，沟通也是非常重要的，做每个功能，都需要沟通，和客户的沟通，和团队的沟通，只有这样，你做出来的功能才能被认可，这样也会提高在项目开发上的效率，才能更快更好的完成项目。

6. 昆明小微企业金融交易项目

  • 项目简介：《结算子系统》是针对小微金融交易目前只有手工财务报表，没有形成统一、规范的财务体系而建立的结算子系统。系统采用 B/S 架构，采用 html+javascript 异步开发技术作为前端开发，采用 java 作为后台编程语言，数据库管理系统为 Oracle。所以要运行此系统必须先安装 JDK、Tomcat 服务器、Oracle 数据库及客户端操作工具，待安装完成后，进行相应的配置，系统就能正常运行了。该系统主要有系统管理、账户管理和报表管理三大部分构成，我在该项目里主要完成账户管理部分，也对其他部分做了理解。账户管理包含了账户开户、账户资料查询、账户记账和日终批处理。
  • 开发工具：eWAP、MyEclipse、plsql、Tomcat 等
  • 技术实现：corejava、socket、javascript、html+js、Jquery 等
  • 总结与体会：通过这个项目，使我的 sql 水平有了很大的提高，因为要做报表，就需要去认识系统所用到的表和理解表的结构，需要写大量的 sql 语句来得出正确的数据结果，需要大量的去验证 sql 的正确性和高效性，促使自己不断的去学习和测试，对自己有很大的帮助。

7. 富滇财政凭证库项目（财政国库集中支付电子化系统）

  • 项目简介：该项目是一个电子凭证系统，设计该系统的目的：一是从基础上筑牢财政资金安全防线，有助于加强廉政风险防控建设。单靠纸质凭证衔接各个业务管理环节，在实际执行过程中经常出现制度执行不到位和信息不对称，造成系统内部审核控制与纸质凭证管理相互脱节，未形成完整的管理链条，给违规使用财政资金以可乘之机。实施支付电子化管理，将原来相对独立分散的安全控制扩展为依靠固化的流程、规则及信息安全技术共同构建的立体“防护网”，确保任何人都无法单独完成财政资金支付交易，支付流程中的任何操作都运行在阳光下，靠系统管资金、管账户、管干部，最大限度的杜绝财政资金管理漏洞，防范财政资金安全风险。二是从根本上提高财政资金运行效率，有助于提升政府部门行政效能。随着财政国库科学化、精细化管理的不断推进，财政国库部门业务处理量迅速增长，就中央本级而言，每年经国库部门办理的支付业务就多达 500 多万笔，传统资金支付管理方式下，业务人员需逐岗手工签章、逐笔打印凭证、每日往返取单送单，耗费大量的人力、物力、财力。实施支付电子化管理，取消纸质凭证流转，不再需要专门印制凭证单据，不再需要进行电子信息与纸质单据的人工核对，预算单位工作人员足不出户即可完成资金支付，预算单位可以“全天候”进行用款业务办理，将工作人员从大量的体力劳动中解放出来，大大降低了行政运行成本，提高了工作效率和财政资金运行效率，政府部门的行政效能得到大幅提升。
  • 设计原则：此次系统开发在行内主要涉及中间业务系统、凭证库管理系统、印章、核心业务系统四个系统。系统开发和改造过程中，尽量对原系统的业务逻辑、操作习惯和账务处理不做大幅度调整，同时考虑系统的可扩展性以及通用性。
  • 开发工具：eWAP、MyEclipse、DBvisualizer、Tomcat 等
  • 技术实现：corejava、socket、javascript、html+js、Jquery 等
  • 总结与体会：通过这个项目，使我的项目经验更上一层楼，因为该项目是我和一同事共同完成的，从项目的开始到结束，我都在这个项目中，该项目开发环境的布置，svn 的搭建到整个框架的构建都有我负责。起初，也遇到了很多问题，比如数据库的连接问题，因为之前的是 oracle，现在要用 DB2 做数据库，待这个问题解决后，启动服务，平台里的系统功能又出问题了，经检查，是后台 sql 的关系，oracle 和 DB2 的语法有一些不同所导致。在这个项目里我主要负责后台，而我同事主要负责前台，这样相互协作，一同开发，在合作过程中我们相互帮忙，遇到问题一起分析，相互提出意见，最后采取比较好的方法来解决问题。
