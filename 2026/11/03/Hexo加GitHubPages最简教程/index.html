Hexo + GitHub Pages 最简教程（一键部署版）

适合 Windows / Mac；先说明：仓库名字必须严格：你的github用户名.github.io，全部小写
最终网址：https://你的用户名.github.io

一、先装 2 个必备软件

  1. Git：https://git-scm.com/ ，一路默认安装
  2. Node.js：官网下载 LTS 长期支持版（自带 npm）

装好之后，打开终端（Windows：PowerShell / CMD），输这两句验证，能显示版本号就 ok：

二、全局安装 Hexo

三、初始化博客

把下面 blog 换成你想要的文件夹名，或者直接用用户名那个名字：

✅ 这一步之后，本地博客就初始化好了

本地预览（先看效果）

打开浏览器访问：http://localhost:4000，就能看到博客页面。按 Ctrl + C 停止本地服务。

四、去 GitHub 建仓库

  1. 登录 github.com → New repository
  2. Repository name：你的用户名.github.io（重点！不能错）
  3. ✅ Public（必须公开，私有仓库 Pages 访问要钱）
  4. 不要勾选 Add a README，直接 Create repository

复制仓库地址，类似：https://github.com/xxx/xxx.github.io.git

七、写文章、生成、上线

1. 新建一篇文章

文章文件在这里：source/_posts/我的第一篇SEO博客.md

👉 就是 Markdown 文件，AI 写好的内容直接粘贴进去，非常方便。

2. 清理缓存 + 生成页面 + 部署上线（一条命令搞定）

  • hexo clean：清理旧缓存
  • hexo g（generate）：生成静态网页
  • hexo d（deploy）：自动推送到 github gh-pages 分支

第一次部署会弹窗让你登录 GitHub，授权即可。

八、开启 GitHub Pages

  1. 打开这个仓库 → Settings → Pages
  2. Build and deployment：
    • Source：Deploy from a branch
    • Branch：选 gh-pages，文件夹选 / (root)
  3. Save，等待 1~3 分钟生效，访问 https://用户名.github.io

✅ 以后日常使用流程（非常简单）

  1. 写新文章：hexo new "标题"
  2. 编辑 source/_posts/xxx.md（放 AI 生成的博客，加 SEO 摘要、关键词）
  3. 预览：hexo s
  4. 发布上线：hexo clean && hexo g && hexo d

⚠️ 新手高频坑

  1. yml 缩进错：deploy 下面两行前面用 2 个空格，不要用 Tab，冒号后必须空格，不然部署报错
  2. 仓库名字写错，网址打不开
  3. 国内访问慢、偶尔打不开（适合谷歌 SEO）
  4. 文章里中文图片：推荐图床（PicGo），不要放本地图片，否则线上看不到
  5. 想要评论：装 Giscus，绑定 github 仓库做评论区

🎨 可选：换好看主题

推荐：Butterfly、Yilia、Next，网上教程很多，直接下载放到 themes 文件夹，改 _config.yml 里的 theme 字段。

📝 附：接入 Giscus 评论

原理：评论存在仓库的 Discussions，访客用 GitHub 账号留言；推荐直接用你的 xxx.github.io 这个仓库
前置：已经装好 Butterfly 主题

1、给仓库开启 Discussions

  1. 打开 xxx.github.io 仓库 → Settings
  2. 往下找到 Features → 勾选 Discussions
  3. 进入 Discussions 标签页 → New category
    • 分类名字：Comments
    • 类型选：Announcements（公告）（推荐，只有你和 Giscus 能新建讨论，防止乱建）
    • 保存，记住这个分类名

2、安装 Giscus GitHub App

打开：https://github.com/apps/giscus

  1. 点 Install
  2. 选择你的账号 → 只选这个 xxx.github.io 仓库（不要选全部仓库）
  3. 授权安装成功

3、去 giscus.app 生成配置参数

打开官网：https://giscus.app/zh-CN

按下面选项填：

  • 仓库：用户名/用户名.github.io
  • 页面 ↔ Discussions 映射：pathname（推荐）
  • Discussion 分类：选刚才新建的 Comments（Announcements）
  • 勾选：启用反应、启用元数据、输入框在底部
  • 主题：preferred_color_scheme（跟随博客明暗模式）
  • 语言：zh-CN

填完后页面下方会出现一段 script 代码，提取 4 个值：

  • data-repo
  • data-repo-id
  • data-category
  • data-category-id

✅ 常见坑

  1. 评论区空白不显示
    • 检查仓库是不是【公开仓库】，私有仓库 Giscus 不能用
    • 确认 Giscus App 已经安装到这个仓库
    • 确认 Discussions 功能打开、分类 ID 复制正确
  2. 国内加载慢：Giscus 是海外 js，网络不好会刷不出来，属于正常情况
  3. 只有文章页显示，首页、关于页默认不出现（Butterfly 默认逻辑）
  4. 访客必须登录 GitHub 才能评论

补充：如果你不是 Butterfly 主题（NexT 等）

就直接把 giscus.app 拿到的那段 <script> 代码粘贴到文章模板底部，不需要主题配置。
